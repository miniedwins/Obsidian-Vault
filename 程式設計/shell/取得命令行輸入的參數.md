說明 : 取得命令行輸入的傳遞參數，可以使用 **shift** 取得每一個參數。

以下範例會確認輸入參數長度是否大於 1，並且執行 `shift` 由右往左移動參數，每移位長度就減 1，直到 0 為止跳出迴圈。

```shell

# 取得輸入參數長度 ($#)
while [ "$#" -ge "1" ]; do
	echo "current parameter: $1" 
	shift 
done
```

執行結果如下 : 

```shell
$ shift.sh 1 2 3
current parameter: 1
current parameter: 2
current parameter: 3
```

若是要取得參數後面的設定值，則是需要移位兩次。

```shell
sections=()

while (($#)); do
        case "$1" in
                -s) echo "s = $1"; sections+=("$2"); shift; shift;;
                -v) echo "v = $1"; sections+=("$2"); shift; shift;;                
                -h) usage; break;;
                *) usage; exit 1;;
        esac
done

# 顯示陣列所有值
echo ${sections[@]}
```

執行結果如下 :

```shell
$ ./shift.sh -s 1 -v 2
s = -s
v = -v
1 2
```
