## 問題
當你需要創建一個嵌套目錄結構。

## 範例
```python
from pathlib import 

Path p = Path('2023/09/11') 
p.mkdir(parents=True, exist_ok=True)
```

## 程式碼說明
```python
p.mkdir(parents=True, exist_ok=True)
```

- 如果設置為 `True`，則會自動創建所有缺失的父目錄。 
	- 父目錄已存在，否則會拋出 `FileNotFoundError`。
	- 若是要忽略異常，需要設定 `exist_ok=True`。
- 如果設置為 `False`（默認值），則只有在父目錄已存在時才會創建目標目錄。
	- 父目錄不存在，則會拋出 `FileNotFoundError`。
