## 問題
當你需要遍歷目錄中的所有檔案和子目錄時。

## 範例
```python
from pathlib import Path

# 當前目錄
my_directory = '.'
entries = Path(my_directory)

# 列出所有檔案和目錄
for entry in entries.iterdir():
    print(entry.name)
```

## 程式碼說明

`iterdir()` 會返回一個迭代器包含目錄中所有的物件，物件包含檔案屬性資訊。

- **作用**：    
    - 返回一個迭代器，包含目錄中所有的物件（檔案和子目錄）。        
    - 每個物件是一個 `Path` 實例，包含檔案或目錄的屬性資訊。        
- **使用場景**：    
    - 當你需要遍歷目錄中的所有檔案和子目錄時，可以使用 `iterdir()`。

```python
for entry in entries.iterdir():
	print(entry.name)
```

另外，生成器表達式，可以讓程式碼更加簡潔，`is_file` 檢查是檔案，若是檔案就會列出。

```python
files = (entry for entry in entries.iterdir() if entry.is_file())
for filename in files:
    print(filename)
```

若是要列出目錄名稱，將呼叫函數 `is_file()` 修改成 `is_dir()`。

```python
dirs = (entry for entry in entries.iterdir() if entry.is_dir())
for dirname in dirs:
	print(dirname)
```
