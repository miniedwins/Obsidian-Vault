## 問題
若是對每個欄位都聲明一個別名（e.g., user_name -> UserName），非常麻煩。 這時候就可以通過設定別名生成器來批次完成。

## 解決方案


## 範例說明
這段程式碼使用了 Pydantic 的 `ConfigDict` 和 `alias_generator` 功能，目的是自動將字段名稱轉換為特定的格式（例如駝峰式命名）。

```python
from pydantic import BaseModel, ConfigDict, Field 

def to_camel(string: str) -> str:
    return ''.join(word.capitalize() for word in string.split('_'))
  
class User(BaseModel):
    model_config = ConfigDict(alias_generator=to_camel)
    user_name: str
    address_code: str = Field(alias='address', alias_priority=2)
  
user = User(**{"UserName": "Edwin", "address": "xyz"})

print(user.address_code)
print(user.model_dump(by_alias=True))
```

- 這個函數的作用是將輸入的字符串轉換為駝峰式命名（CamelCase）。    
- 例如：    
    - `user_name` → `UserName`        
    - `address_code` → `AddressCode`

```python
def to_camel(string: str) -> str:
    return ''.join(word.capitalize() for word in string.split('_'))
```

- `ConfigDict` 是 Pydantic V2 中用於配置模型行為的工具。    
- `alias_generator=to_camel` 表示為模型中的每個字段自動生成一個別名（alias），並使用 `to_camel` 函數來生成別名。

```python
class User(BaseModel):
	model_config = ConfigDict(alias_generator=to_camel)
```

- `Field` 用於定義字段的額外配置。    
- `alias='lang'` 表示為 `language_code` 字段手動設置一個別名 `lang`。
- `alias_priority=2` 表示這個手動設置的別名優先級高於自動生成的別名（`AddressCode`）。       - 優先級越高，Pydantic 會優先使用該別名。

```python
address_code: str = Field(alias='AddressCode', alias_priority=2)
```

## 補充說明
 - `alias_priority`，這個參數主要控制別名生成器的優先順序。
	 - `None`，如果定義了 alias，則使用 alias，不然使用別名生成器。
	 - `1`，使用別名生成器，如果未定義別名生成器，則使用欄位名。
	 - `2`，不使用別名生成器，使用欄位名。
