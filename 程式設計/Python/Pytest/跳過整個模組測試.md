## 說明
使用標記過濾測試函數，主要用來跳過某些未完成的測試項目。

## 參數
- `@pytest.mark.skip`
	- **reason** (`str`) : 
		- 設置跳過測試的理由。
	- **allow_module_level** (`bool`) : 
		- 預設為 `False`。
		- 設定為 `True` 時可以讓測試模組層級被跳過。

## 範例
如果操作系統是 Linux，則跳過整個模組的測試並給出相應的理由。

```python
if sys.platform.startswith("linux"):
    pytest.skip("reason=Only tests for Windows platform", allow_module_level=True)
```
