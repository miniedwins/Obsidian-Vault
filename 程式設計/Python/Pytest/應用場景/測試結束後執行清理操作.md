`request.addfinalizer()` 是 `pytest` 提供的一個功能，用於在測試結束後執行 **清理操作**。它通常用於釋放資源、刪除臨時文件、關閉連接等場景。

- **功能**：    
    - 註冊一個函數，該函數會在測試結束後執行。        
    - 無論測試成功還是失敗，註冊的函數都會被執行。        
- **使用場景**：    
    - 釋放資源（如關閉文件、數據庫連接）。        
    - 刪除臨時文件或目錄。
    - 重置測試環境。

## 測試範例
### (1) 單一清理函數
`addfinalizer()` 通常與 `fixture` 一起使用，以確保資源在測試結束後被正確釋放。

- `temporary_file` 
	- fixture 創建一個臨時文件，並在測試結束後刪除它。        
- `request.addfinalizer(cleanup)`
	- 註冊了 `cleanup` 函數，該函數會在測試結束後執行。

```python
import pytest

@pytest.fixture
def temporary_file(request):
    # 創建臨時文件
    file_path = "temp_file.txt"
    with open(file_path, "w") as f:
        f.write("Hello, World!")

    # 註冊清理函數
    def cleanup():
        import os
        if os.path.exists(file_path):
            os.remove(file_path)
            print(f"Deleted temporary file: {file_path}")

    request.addfinalizer(cleanup)
    return file_path

def test_temporary_file(temporary_file):
    with open(temporary_file, "r") as f:
        content = f.read()
    assert content == "Hello, World!"
```

### (2) 處理多個清理函數
多次調用 `request.addfinalizer()`，註冊多個清理函數。這些函數會按照順序執行。

```python
@pytest.fixture
def multiple_cleanups(request):
    # 註冊多個清理函數
    def cleanup_1():
        print("Cleanup 1")

    def cleanup_2():
        print("Cleanup 2")

    request.addfinalizer(cleanup_1)
    request.addfinalizer(cleanup_2)

def test_multiple_cleanups(multiple_cleanups):
    assert True
```
