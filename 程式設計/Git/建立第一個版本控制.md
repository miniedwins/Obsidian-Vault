首先需要設定使用者名稱與信箱

```shell
git config --global user.name "your name"
git config --global user.email "your e-mail"
git config --global color.ui true
```

然後執行 git 初始化命令，建立 **Git Repository**

```shell
git init
```

接下來完成第一個版本控制

```shell
echo README > README.md
git add README.md
git commit -m "First Commit"
```
