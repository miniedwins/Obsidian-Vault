命令縮寫可以幫助我們減少大量的輸入命令字串，例如下列情況 : 

```shell
# example : commit -> cm

$ git commit -m "First Commit"
$ git cm -m "First Commit"

# example : branch -> br

$ git branch feature
$ git br feature
```

**命名方法** 
* git config --global alias.[name] [command_name]

直接在終端機下使用 `git config` 設定

```shell
git config --global alias.cm commit
git config --global alias.co checkout
git config --global alias.br branch
git config --global alias.st status
git config --global alias.lg 'log --oneline --graph'
```

也可以到當前目錄上的 `.git/config` 檔案裡透過 `alias` 設定

```
[alias]
  co = checkout
  br = branch
  st = status
  l = log --oneline --graph
  ls = log --graph --pretty=format:"%h <%an> %ar %s"
```

設定完成後，列出當前設定的參數

