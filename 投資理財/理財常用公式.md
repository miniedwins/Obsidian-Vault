
# 殖利率

**公式 : 每股盈餘 (EPS) / 股價**

# 如何計算盈餘分配率

**公式 : ( 每股股利 / 每股盈餘 ) x 100%**

範例 :  假設公司去年賺 EPS 1.51元，預計今年配發現金股利 1 元 以及股票股利 0.3 元
* 現金分配率 : 1 / 1.51 = 66.7 %
* 股利分配率 : 0.3 / 1.51 = 19.9 %
* 合計分配率 : 66.7 + 19.9 = 86.6 %

# 預估明年配發股利與比例

**公式 : 年平均盈餘分配率 x 今年的 EPS** 

範例 : 假設公司今年的 EPS 1.36元，平均5年盈餘分配率 86.74 %
* 明年預估的股利 : 1.36 x 86.74% = 1.18

範例 : 假設公司近5年平均分配率為現金 70 % 股票 15 %，則明年配發比例
* 現金 : 1.18 x 70 % = 0.82
* 股票 : 1.18 x 15 % = 0.18

# 合理計算當前股價 (存股)

**公式 : 平均 (EPS) / 目標殖利率 (4/5/6)**

範例 : 假設公司5年平均 EPS = 2 元，目前的股價為 60 元
- 便宜價 : 2 / 6% = 33.3元
- 合理價 : 2 / 5% = 40元
- 昂貴價 : 2 / 4% = 50元
