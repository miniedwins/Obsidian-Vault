
`shift` 指令的作用是將輸入參數向左移動。例如執行一次 `shift`，原本的 `$2` 會變成 `$1`，而 `$#` (參數總數) 會減 1。這在處理不確定數量的參數或開發 CLI 工具時非常實用。

## 🚀 範例一：基礎循環處理

**場景：** 當你需要逐一處理所有傳入的參數，但不知道參數總數時。

```shell
#!/bin/bash

echo "開始處理參數，總數：$#"

# 當參數個數 ($#) 大於等於 1 時持續循環
while [ "$#" -ge 1 ]; do
    echo "當前處理位元 (\$1): $1"
    
    # 核心動作：將參數左移，丟棄目前的 $1，讓 $2 遞補上來
    shift 
done

echo "處理完畢，剩餘參數個數: $#"
```

### 執行與結果

```shell
$ ./shift_basic.sh A B C
開始處理參數，總數：3
當前處理位元 ($1): A
當前處理位元 ($1): B
當current 處理位元 ($1): C
處理完畢，剩餘參數個數: 0
```

## 🛠️ 範例二：進階選項解析 (Flags & Options)

**場景：** 模擬標準 Linux 指令（如 `-s value`），利用 `case` 搭配 `shift` 來解析特定的選項與其對應的數值。

```shell
#!/bin/bash

# 初始化存放結果的陣列
sections=()

# 幫助訊息函式
usage() {
    echo "用法: $0 [-s value] [-v value] [-h]"
    echo "  -s : 指定 Section 名稱"
    echo "  -v : 指定 Version 數值"
    echo "  -h : 顯示說明"
}

# 只要還有參數就繼續解析
while (($#)); do
    case "$1" in
        -s|-v) # 處理帶有參數的選項
            echo "檢測到選項 $1，對應值為: $2"
            sections+=("$2")
            shift 2  # 跳過選項名稱與其數值（移位兩次）
            ;;
        -h) # 顯示幫助
            usage
            exit 0
            ;;
        *) # 遇到未知選項
            echo "錯誤：未知選項 [$1]"
            usage
            exit 1
            ;;
    esac
done

echo "--- 解析完成 ---"
echo "收集到的設定值: ${sections[@]}"
```

### 執行與結果

```shell
$ ./parse_options.sh -s Server1 -v 2.0
檢測到選項 -s，對應值為: Server1
檢測到選項 -v，對應值為: 2.0
--- 解析完成 ---
收集到的設定值: Server1 2.0
```

---

## 💡 學習要點總結

1. **`$#` 的動態變化**：每次執行 `shift`，`$#` 都會自動遞減。
    
2. **`shift N`**：預設是 `shift 1`，但在處理「選項+數值」的情況下（如 `-s 100`），需要使用 `shift 2` 來一次跳過兩個參數。
    
3. **防止無窮迴圈**：在使用 `shift` 的 `while` 迴圈中，務必確保所有邏輯分支最終都會執行到 `shift`，否則會因為 `$#` 永遠不減小而導致死鎖。
