# 寫入自訂資料

參數 : buffer_pattern=str
說明 : 寫入的資料內容 ( 例如 : 0x55AA )

```shell
$ fio --filename=/dev/sdb --name=mytest --ioengine=libaio --iodepth=1 --rw=write --bs=4k --direct=1 --numjobs=1 --group_reporting --buffer_pattern=0x55AA -size=1024M
```

# 讀取自訂資料並且驗證正確性

參數 1 : verify_pattern=str
說明 : 驗證的資料內容 ( 例如 : 0x55AA )

參數 2 : verify=pattern
說明 : 指定字串 "pattern" 來驗證

```shell
$ fio --filename=/dev/xxx --name=mytest --ioengine=libaio --iodepth=1 --rw=read --bs=4k --direct=1 --numjobs=1 --group_reporting --verify_pattern=0x55aa --verify=pattern
```
