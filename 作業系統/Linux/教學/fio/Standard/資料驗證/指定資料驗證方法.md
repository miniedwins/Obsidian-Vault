**參數** : `do_verify=bool` 
**說明**：  
- 控制是否進行寫入後的資料驗證。
- 預設值為 **`TRUE`**（啟用驗證），即使不明確指定，系統也會自動驗證。
- 若禁用（設為 **`FALSE`**），即使有指定 `verify` 方法，仍不會進行驗證。

**參數** : `verify=str`
**說明** : 
- 指定資料驗證的方式，用於檢查寫入後的數據完整性。
- 支援多種驗證方法，例如：
	- **`crc32`**：循環冗余校驗（快速檢查）
	- **`md5`**：更強的資料校驗
	- **`sha256`**：高安全性校驗

**範例** : 
- 驗證寫入數據完整性，使用 CRC32 方法：
```shell
$ fio --filename=/dev/nvme0n1 --name=mytest --ioengine=libaio --direct=1 --iodepth=32 --bs=128k --rw=write --size=100% --do_verify=1 --verify=crc32
```

如何驗證剛剛寫入的資料是否有錯誤，RW 更改成 `--rw=read` 即可以驗證資料是否有誤。

```shell
fio --filename=/dev/nvme0n1 --name=mytest --ioengine=libaio --direct=1 --iodepth=32 --bs=128k --rw=read --size=100% --do_verify=1 --verify=crc32
```

為了驗證資料這個動作的真實性，使用 DD 命令覆寫原先的資料，包含 CRC32 整個都會被覆寫

```shell
$ dd if=/dev/urandom of=/dev/nvme0n1 bs=1024k count=10
```
