參數 1 : do_verify=bool ( Default：True)
說明 1 : 只要有指定 `verify=xxx`，寫入資料後就會執行驗證，沒有指定則不會驗證。
說明 2 : 因為初始值為 "TRUE"，可以不用特別設定。

參數 2 : verify=str
說明 : 資料驗證方法有很多種類，例如：CRC32、 MD5、SHA256 ... 等等。

```shell
$ fio --filename=/dev/nvme0n1 --name=mytest --ioengine=libaio --direct=1 --iodepth=32 --bs=128k --size=100% --do_verify=1 --verify=crc32 --rw=write
```

如何驗證剛剛寫入的資料是否有錯誤，RW 更改成 `--rw=read` 即可以驗證資料是否有誤

```shell
fio --filename=/dev/nvme0n1 --name=mytest --ioengine=libaio --direct=1 --iodepth=32 --bs=128k --size=100% --do_verify=1 --verify=crc32 --rw=read
```

為了判斷驗證資料這個動作的真實性，使用 DD 命令覆寫原先的資料，包含 CRC32 整個都會被覆寫

```shell
$ dd if=/dev/urandom of=/dev/nvme0n1 bs=1024k count=10
```
