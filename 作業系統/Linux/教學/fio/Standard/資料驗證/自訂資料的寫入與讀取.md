# 寫入自訂資料

參數 : buffer_pattern=str
說明 : 寫入的資料內容 ( 例如 : 0x55AA )

```shell
$ fio --filename=/dev/sdb --name=mytest --direct=1 --numjobs=1 --ioengine=libaio --iodepth=1 --bs=128k --rw=write --size=100% --group_reporting --buffer_pattern=0x55aa 
```

# 讀取自訂資料並且驗證正確性

參數 1 : verify_pattern=str
說明 : 驗證的資料內容 ( 例如 : 0x55AA )

參數 2 : verify=pattern
說明 : 指定字串 "pattern" 來驗證

```shell
$ fio --filename=/dev/sdb --name=mytest --direct=1 --numjobs=1 --ioengine=libaio --iodepth=32 --bs=128k --rw=read --size=100% --group_reporting --verify_pattern=0x55aa --verify=pattern
```
