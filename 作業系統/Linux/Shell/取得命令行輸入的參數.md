## **範例一：逐一處理參數**

說明 : 
- 檢查輸入參數，逐一列印每個參數的值，直到所有參數處理完畢。 

```bash
# 檢查參數長度，依序處理 
while [ "$#" -ge 1 ]; do
	echo "Current parameter: $1"     
	shift  # 移位，處理下一個參數 done
```
   
執行與結果：

```bash
$ ./shift.sh 1 2 3 
Current parameter: 1 Current parameter: 2 Current parameter: 3
```
 
## **範例二：解析帶參數選項**

說明 : 
- 支援選項（如 `-s` 和 `-v`），並記錄其後的設定值到陣列。  
- 若遇到未定義選項，則返回錯誤提示。

```bash
# 初始化陣列
sections=()

# 解析參數選項
while (($#)); do
    case "$1" in
        -s)  # 選項 -s 的處理
            echo "Option -s detected: $1"
            sections+=("$2")  # 記錄值到陣列
            shift 2  # 移位兩次，跳過選項和值
            ;;
        -v)  # 選項 -v 的處理
            echo "Option -v detected: $1"
            sections+=("$2")
            shift 2
            ;;
        -h)  # 顯示使用幫助
            usage
            exit 0
            ;;
        *)   # 遇到未知選項
            echo "Unknown option: $1"
            usage
            exit 1
            ;;
    esac
done

# 顯示處理後的陣列內容
echo "Sections: ${sections[@]}"

```

執行與結果：

```bash
$ ./shift.sh -s 1 -v 2
Option -s detected: -s
Option -v detected: -v
Sections: 1 2
```
