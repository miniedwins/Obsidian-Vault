## 查詢裝置的詳細資訊

**命令** : 
- `lspci` 
**參數說明** : 
- `-s` : 篩選特定設備。你可以指定 PCI 的位址，例如 `-s 01:00.0`。
- `-v` : 顯示基本資訊（verbose）。
- `-vv` : 顯示更多的內容，會提供每個設備的完整資訊。

## 顯示暫存器配置空間數值

**命令** : 
- `lspci -s -xxx`
**參數說明** : 
- `-xxx` : 顯示 PCI 設備的原始配置空間數據（Hexadecimal 格式）。
