1. 結構正確性:新的檔案/模組切分是否完整,有沒有遺漏或重複的職責

3. 循環依賴:畫出依賴方向圖(A → B),指出任何環,並說明路徑
4. 分層:各層的職責與依賴方向(上層只依賴下層)是否一致,有沒有跨層呼叫
5. 風險:遷移順序、相容性(對外 API / 命令碼 / 回應格式)、測試如何確保行為不變
6. 計畫本身:步驟是否可執行、可回滾,有沒有含糊或缺漏的地方
