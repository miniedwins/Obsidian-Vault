
# Test Title

**Format Namespace with Crypto Erase  
when Namespace Global Range Exists without Any Non-Global Range**

---

## Test Description

This test verifies the controller behavior when executing  
**Format Namespace with Crypto Erase (SES = 0x002)**  
under the condition that **each Namespace has only a Global Range and no associated Non-Global Range**.

The purpose is to confirm that:

- The Format command is accepted successfully.
    
- The encryption key is updated correctly.
    
- No unexpected data loss or access failure occurs due to the absence of Non-Global Ranges.
    

---

## Test Environment

- Storage device supports **NVMe Format Namespace**.
    
- TCG OPAL is supported and initialized.
    
- Three Namespaces are available:
    
    - NS1 (NSID = 0x01)
        
    - NS2 (NSID = 0x02)
        
    - NS3 (NSID = 0x03)
        
- Each Namespace has:
    
    - One **Namespace Global Range** assigned.
        
    - **No Non-Global Range** associated.
        
- All Locking Ranges are in **Read/Write Unlocked** state.
    
- Test environment ensures the above conditions before executing this test.
    

---

## Test Steps

### Step 1: Write Test Data

Write identical test data _Data(A)_ to each Namespace.

- Write: NSID=0x01, Start LBA=0, Length=64, Pattern=Data(A)
    
- Write: NSID=0x02, Start LBA=0, Length=64, Pattern=Data(A)
    
- Write: NSID=0x03, Start LBA=0, Length=64, Pattern=Data(A)
    

---

### Step 2: Format Namespace with Crypto Erase

Execute Format Namespace with Crypto Erase on each Namespace.

- Format: NSID=0x01, SES=0x002 (Crypto Erase), LBAF=512
    
- Format: NSID=0x02, SES=0x002 (Crypto Erase), LBAF=512
    
- Format: NSID=0x03, SES=0x002 (Crypto Erase), LBAF=512
    

---

### Step 3: Data Verification

Read back user data from each Namespace.

- Read: NSID=0x01, Start LBA=0, Length=64
    
- Read: NSID=0x02, Start LBA=0, Length=64
    
- Read: NSID=0x03, Start LBA=0, Length=64
    

---

## Expected Result

### Step 2

- The controller returns **SUCCESS** for all three Format commands.
    

### Step 3

- Data read from NS1, NS2, and NS3 is accessible without error.
    
- Data content matches _Data(A)_.
    
- No unexpected access restriction or data corruption occurs.
    

---

## Notes

- This test focuses on **command acceptance and key transition behavior**  
    when no Non-Global Range exists.
    
- Cryptographic data sanitization itself is **out of scope** for this test.
