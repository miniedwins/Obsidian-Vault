### 問題 1：控制器發現主機端送出命令的 MIC 錯誤，應該如何處理？

**控制器端的行為** : 根據規範，如果 MIC 驗證失敗 → 控制器必須丟棄整個 Message。這個動作是 silent discard (靜默丟棄，不回應)，也就是控制器不會送回 Error Response 或 NACK。

**主機端的檢測方式**  : 由於控制器完全不會回覆，主機端無法直接知道 MIC 錯誤。主機端必須依靠 Timeout 機制，主機等待 Response Message。若在規範的時間內沒有收到回覆 → 主機推測該 Request 可能遺失或 MIC 錯誤而被丟棄。然後主機端需重送該命令 (Retry)。
