# HCTM 介紹

控制器提供主機端一個溫度設定機制 **( HCTM )**，讓主機端 ( Host ) 可以通過特定的組態設定不同階段的熱管理 **( TMT1 and TMT2 )**，指示控製器在達到溫度的設定閥值，自動不同的電源狀態之間切換，並且執行特定熱管理動作。這些操作的目標是幫助裝置在運行過程中保持在主機指定的熱管理範圍內。

因此，控製器可以根據當前的溫度狀況選擇功耗較低的模式，以減少發熱量，或者在需要更高性能時切換到更高的電源狀態。

> **供應商特定的熱管理動作** : 除了切換電源狀態，控製器還可能執行一些由供應商定義的特定操作，這些操作可能與裝置的散熱機制、CPU 速度控制等相關，旨在更好地管理裝置的溫度。

# 檢查是否支援 HCTM

**主機控制的熱管理支援** : 控製器是否支援 HCTM 由控製器 `Identify Ctrl` 結構中的“主機控制的熱管理屬性”欄位表示。如果支援，這意味著控製器可以響應主機的熱管理請求。
