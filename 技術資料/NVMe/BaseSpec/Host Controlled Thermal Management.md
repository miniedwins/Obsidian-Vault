# HCTM 介紹

1. **主機控制的熱管理支援** : 控製器是否支援 HCTM 由控製器識別資料結構中的“主機控制的熱管理屬性”欄位表示。如果支援，這意味著控製器可以響應主機的熱管理請求。
   
2. **熱管理機制** : 當啟用 HCTM 時，主機可以通過特定的組態，指示控製器根據主機的需求自動在不同的活躍電源狀態之間切換，或者執行一些由供應商定義的特定熱管理動作。這些操作的目標是幫助裝置在運行過程中保持在主機指定的熱管理範圍內。

3. **電源狀態切換** : 控製器可以根據主機的指令，在不同的活躍電源狀態之間進行切換。這樣，控製器可以根據當前的溫度狀況選擇功耗較低的模式，以減少發熱量，或者在需要更高性能時切換到更高的電源狀態。

4. **供應商特定的熱管理動作** : 除了切換電源狀態，控製器還可能執行一些由供應商定義的特定操作，這些操作可能與裝置的散熱機制、速度控制等相關，旨在更好地管理裝置的溫度。
