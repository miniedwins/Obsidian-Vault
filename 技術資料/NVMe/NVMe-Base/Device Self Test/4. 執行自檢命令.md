指定 Namespace Id 以及 Self-test Code ( STC )，發送自檢命令給控制器執行操作。

發送命令前需要了解 **Namespace Test Action** 所描述的說明。

# 指定自檢類型

指定哪一個自檢測試類型，只少會有兩個類型可以設定。

~~~shell
# Short self-test
nvme device-self-test /dev/nvme0 --namespace-id=1 --self-test-code=1

# Extended self-test
nvme device-self-test /dev/nvme0 --namespace-id=1 --self-test-code=2
~~~
# 停止自檢命令

指定取消自檢命令。

~~~shell
# Abort the device self-test
nvme device-self-test /dev/nvme0 --namespace-id=1 --self-test-code=0xf
~~~

# 查詢 Extended 自檢完成時間

- 發送 **Identify Controller** 命令來取得 `EDSTT` 需要多少時間內完成測試。
- `EDSTT` 結果轉換成 `10` 進制，取得真正的測試時間。
- 如果控制器沒有支援，這個欄位就是保留狀態。

![[extented_device_self_test_time.png]]

- 輸出結果 :  5分鐘完成 **Extended Device Self Test**。

```shell
$ nvme id-ctrl /dev/nvme0 | grep edstt
# edstt: 5
```
