---

## 🎨 狀態圖示說明

- 🟢 **已完成** - 任務全部完成
- 🔵 **進行中** - 正在執行
- 🟡 **待處理** - 尚未開始
- 🔴 **已延遲** - 超過預定時間
- ⚫ **已取消** - 不再執行

---

## ✏️ 更新規則

### 完成子任務時

```markdown
更新前：
- [ ] 子任務 2：描述

更新後：
- [x] 子任務 2：描述 ✅ 2026-01-07 15:30

同時更新：
- 進度：1/5 (20%) → 2/5 (40%)
- 更新時間
- 移動 👈 標記到下一個子任務
```

### 完成整個任務時

```markdown
1. 更新 tasks.md：
   - 狀態改為 🟢 已完成
   - 填寫實際完成日期
   - 移至「已完成任務」區域

2. 更新 current-tasks.md：
   - 從「當前執行中任務」移除
   - 更新今日進度總覽
   - 將下一個待處理任務移到執行中
```

---

## 📌 重要提醒

1. **兩個文件用途不同**
    
    - `current-tasks.md` - 快速參考，只顯示當前重點
    - `tasks.md` - 完整記錄，保存所有歷史
2. **更新頻率**
    
    - 完成子任務 → 立即更新兩個文件
    - 任務狀態改變 → 立即更新
    - 不要累積多個變更才更新
3. **保持同步**
    
    - 兩個文件的資訊必須一致
    - current-tasks.md 是 tasks.md 的精簡版
